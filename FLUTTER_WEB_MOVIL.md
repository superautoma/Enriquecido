# Flutter Web desde el móvil

Este repositorio está preparado para usar GitHub Codespaces como entorno de desarrollo Flutter Web.

1. Abre el repositorio en GitHub.
2. Pulsa **Code** > **Codespaces** > **Create codespace on main**.
3. Espera a que termine la preparación inicial.
4. Abre el menú de tareas de VS Code y ejecuta **Flutter Web móvil**, o abre un terminal y ejecuta:
   ```
   cd flutter
   flutter run -d web-server --web-hostname 0.0.0.0 --web-port 3000
   ```
5. Abre el puerto 3000 desde la pestaña **PORTS**.

Para refrescar después de cambios, vuelve al terminal donde corre Flutter y pulsa `r`.
